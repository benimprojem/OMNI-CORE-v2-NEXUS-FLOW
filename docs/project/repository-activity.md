## How to record future snapshots

When updating this file, record:

- The date and time the GitHub Insights page was checked (include timezone).
- The total clone count shown for the selected period.
- The unique-cloner count, if shown.
- The exact reporting window (for example, the last 14 days or a manually calculated 48-hour interval).
- Whether the figure is a cumulative total, a daily count or a period increment.

Do not mix cumulative clone totals with daily or 48-hour increments. Do not infer missing days from the chart or publish a number without its reporting window.
